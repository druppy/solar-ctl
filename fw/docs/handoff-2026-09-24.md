## Gotchas that will bite you
- **WiFi credentials are not in git and not on the previous box either** (`.rules`
  names a gitignored `.zed/tasks.json` that does not exist there). The human must
  supply `SOLAR_WIFI_SSID/PSK/COUNTRY` via env or a `.kas-wifi-local.yml` fragment
  — README has both routes. Ask, do not invent.
- Never `rm_work_and_downloads`. `S = "${UNPACKDIR}"`, not `${WORKDIR}`. A dangling
  `.bbappend` in an active layer is a hard ERROR. GitHub mirrors only
  (`git.yoctoproject.org` 403s here).
- Never OTA `bootcode.bin`/`start.elf`. Keep p1 FAT writes rare.
- Do **not** assert `cmdline=`/`kernel=`/`autoboot.txt` work on BCM2835 — that is
  precisely what tests 1 and 2 exist to determine.
- Terminal here may be `dash` (no `[[`, no `<(...)`); validate probe edits with
  `busybox sh -n` and `busybox awk`, not just GNU tools.
- Docs-only changes do **not** rotate the CI cache key. PR runs cost runner minutes
  but zero cache quota. Never `git add -A` with scratch files lying around (it
  committed a `.commitmsg` once here).
