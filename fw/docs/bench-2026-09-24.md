## Bugs (not tier-related)

- Image has **no WiFi firmware** (`linux-firmware-rpidistro-bcm43430` missing) — serial only.
- Root never resized (135 MB on 122 GB). Fatal for a 350 MB-slot layout; fix before test 5.
- p1 is rw-by-default in this image (left `ro` after tests). FT232R adapter was dead; CH341 works.
