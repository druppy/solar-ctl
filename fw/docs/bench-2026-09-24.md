## Test 5 gotchas (fixed or step-5 work)

- **`CONFIG_SQUASHFS=m` panics**: first milestone image died `VFS: Unable to
  mount root fs on unknown-block(179,2)` — squashfs was a module and there is
  no initramfs. Fix: `CONFIG_SQUASHFS=y` in `solar-ctl-slim.cfg` (and drop the
  then-nonexistent `kernel-module-squashfs` package). `[bench]`
- **libubootenv needs `/boot/uboot.env` to pre-exist** (exactly 16 KiB =
  `CONFIG_ENV_SIZE`): first `fw_printenv`/`fw_setenv` fails "Cannot initialize
  environment"; seed with `dd if=/dev/zero … count=16` + `fw_setenv -s` once.
  Step 5: ship the env blob via `IMAGE_BOOT_FILES` instead. `[bench]`
- U-Boot boot noise (harmless, costs ~1 s): `Card did not respond to voltage
  select! : -110` + empty EFI bootmanager before the p1 script bootflow fires.
  `[bench]`

## Bugs (not tier-related)

- Image has **no WiFi firmware** (`linux-firmware-rpidistro-bcm43430` missing) — serial only. (Fixed: explicit `IMAGE_INSTALL`, 2026-09-25 smoke image.)
- 2026-09-25 smoke image: firmware present but **no `wlan0`** — brcmfmac runtime-requests the vendor plugin `brcmfmac-cyw` (no modpost softdep ⇒ never auto-installed; `brcmf_fwvid_request_module: mod=cyw: failed 256`). Fix: `kernel-module-brcmfmac-cyw` in `IMAGE_INSTALL`
  (fixed image verified 2026-09-25: `wlan0` up, WPA associated, DHCP `192.168.0.53/24`).
- Root never resized (135 MB on 122 GB). Fatal for a 350 MB-slot layout; fix before test 5.
- p1 is rw-by-default in this image (left `ro` after tests). FT232R adapter was dead; CH341 works.
